## 🧠 About Me

> *"I believe the best developers don't just write code — they design systems."*

I'm a highly motivated technologist with hands-on proficiency in **full-stack development**, **AI automation**, and **cybersecurity**. My approach combines rapid prototyping with AI-assisted architecture — going from idea to deployed cross-platform application faster than traditional workflows.

My core methodology revolves around the **Antigravity Framework** — taking functional web builds and seamlessly translating them into native **Android** and **PC** architectures via Electron & Proton. I'm also a passionate creator making tech education content on **YouTube**.
